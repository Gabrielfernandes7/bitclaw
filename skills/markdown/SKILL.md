# Markdown

- Um único `#` (H1) por arquivo, na primeira linha. Não pule níveis de título.
- Linha em branco antes e depois de títulos, listas, tabelas e blocos de código.
- Listas com `-`. Numeradas com `1.` repetido. Aninhe com 2 espaços (bullet) ou 3 (numerada).
- Bloco de código com três crases e a linguagem: ```` ```bash ````.
- Comandos, arquivos e nomes de funções em `` `crase` ``.
- Tabela: linha de cabeçalho, depois `| --- | --- |`, depois as linhas.
- Link: `[texto](url)`. Imagem: `![descrição](caminho)`, com descrição obrigatória.
- Aspas retas (`"`). Fora de código, escape `<` como `\<`.
- Alerta: `> [!NOTE]` e o texto na linha seguinte com `>`. Use poucos.
- Frontmatter `---` no topo é metadado, não conteúdo.
- Docs da Microsoft Learn (`:::`, `[!INCLUDE]`): leia `references/microsoft-learn.md`.
