# Pilares do Teste

## 1. Teste Unitário
- Verifica comportamento de código individual.
- Usa frameworks como pytest ou unittest.
- Foca em lógica isolada.

## 2. Teste de Integração
- Valida interações entre módulos/servicos.
- Simula fluxos completos de uso.
- Garante consistência entre componentes.

## 3. Teste de Sistema
- Avalia o sistema como um todo.
- Inclui cenários reais de produção.
- Mede desempenho e estabilidade.

## 4. Teste de Operação
- Confirma funcionalidades do usuário final.
- Realiza testes manuais e de borda.
- Documenta casos críticos.
